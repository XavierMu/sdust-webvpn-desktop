首次使用 · 两步开始

          
        

        

          
    
            
  1. 
              登录统一身份认证
              在下方「账号与证书」里填账号与密码，点「保存并登录」。
                密码用 Windows DPAPI 加密保存在本机，只需填一次，登录态之后自动续期。
            
    2. 
            
  2. 
              开启系统代理
              填完账号点「保存并登录」，再点「开启系统代理」。
                核心（本地代理 127.0.0.1:8899）是随程序自动启动的，不用手动开；
                真正动你网络设置的是「开启系统代理」这一步，点它的时候如果有还没做的事
                （装根证书、系统代理被别的软件占着），会先问一句。
            
    3. 
          

          

            证书没装的时候，第一次点「开启系统代理」会提示装一次（HTTPS 透明转发必需，装不装都能先用）。
            之后浏览器、git、pip、npm 直接用校内原始地址（如 https://my.sdust.edu.cn）即可，
            不用再打开 webvpn 门户。模式（全局 / PAC）和自定义规则在「分流规则」里改。
          

          

            点窗口 X 只是隐藏到托盘（程序继续在后台跑）；托盘「退出」才会停核心并自动还原系统代理。
          

          

            关于：和翻墙软件的冲突
            
              本程序靠 Windows 的系统代理这个开关工作；翻墙软件（Clash、v2rayN 等）的
              「系统代理」模式会抢同一个开关，谁后写谁生效，校内网站就会打不开或者登录失败。
            
            
              要用翻墙软件，请切到它的 TUN / 虚拟网卡模式，并把
              *.sdust.edu.cn 与学校地址段设为直连（DIRECT），
              否则统一身份认证容易出验证码甚至直接失败。
            
            拿不准就点「连接」卡里的 状态检查，看一眼现在是谁占着系统代理。
          

        

        

          
          
        

      

    


    
    

      

        

          
还没登录统一身份认证

          
        

        

          

            校内资源需要登录后才能访问。请在「账号与证书」里填写账号与密码，
            点「保存并登录」。
          

          

            登录不依赖核心：核心是随程序自动跑的，先登录，再点「开启系统代理」。密码仅以 DPAPI 密文保存在本机。
          

        

        

          
          
        

      

    


    
    

      

        

          
还差一步：装一次根证书

          
        

        

          

          

            用网页访问 https://… 的校内站点时，本机要先信任一张本地根证书，HTTPS 才能透明转发。
            没装之前，浏览器会直接报「您的连接不是私密连接 / 证书不受信任」。
          

          
    
            
  1. 
              点下面的「立即安装」
              Windows 会弹一次确认框，点「是」即可，不用改任何设置。
            
    2. 
            
  2. 
              装完就能用了
              只需一次。以后想撤销，在「账号与证书」里点「卸载」。
            
    3. 
          

          

            证书只装进当前用户的「受信任的根证书颁发机构」，不写系统级证书库，
            也不需要管理员权限。
          

        

        

          
          
          
        

      

    


    
    

      

        

          
登录失败

          
        

        

          

          
最常见的原因：

          
    
            
  • 账号或密码写错了 —— 注意大小写、中英文输入法和多余空格。
    • 
            
  • 密码已过期 —— 学校要求定期改密，去统一认证改完再填一次。
    • 
            
  • 需要验证码 —— 连续失败或异地登录时，统一认证会要求验证码，先在浏览器里登录一次即可。
    • 
          

          

        

        

          
          
        

      

    


    
    

      

        

          
核心没能启动

          
        

        

          

          
常见原因：

          
    
            
  • 代理端口被占用 —— 换一个端口（连接卡片里的「代理端口」）再点保存。
    • 
            
  • 系统代理改不动 —— 可能被安全软件或组策略锁住了，可以先手动关掉系统代理再试。
    • 
            
  • 本机还有另一个副本在运行 —— 控制端口 8897 是固定的，同一时间只能有一个。
    • 
          

          
详细原因在右侧的日志里也有一条。

        

        

          
        

      

    


    
    

      

        

          
清除本机账号？

          
        

        

          
会做这三件事：

          
    
            
  • 删掉本机保存的账号密码 —— `.secrets` 里那份 Windows 加密存储的凭据。
    • 
            
  • 清掉当前登录态 —— 下次访问校内站点要重新登录。
    • 
            
  • 停掉核心并还原系统代理 —— 如果它正在运行。
    • 
          

          
根证书不受影响。清完之后重新填账号密码、点「保存并登录」就能继续用。

        

        

          
          
        

      

    


    
    

      

        

          
系统代理正被别的程序占用

          
        

        

          

            检测到系统代理已经指向 （通常是翻墙软件的系统代理模式）。
          

          
继续接管会把它顶掉；本程序「关闭系统代理」或退出时会还原成现在这样。

          

            在用翻墙软件的 TUN / 虚拟网卡模式？那直接继续就行。如果是它的「系统代理」模式，
            两个会互相顶，建议只留一个。
          

        

        

          
          
        

      

    


    
    

      

        

          
状态检查

          
        

        

          
正在检查…

          

          

            检查会真的发请求：账号走一次校内接口，核心借本机代理访问一次学校首页（只读），
            所以要等几秒。结果会同步到顶栏的状态灯。
